# UberTruck 24/7 — MVP

Prototipo inicial para cotizar y gestionar el alquiler de maquinaria pesada y transporte especializado.

## Demo pública

https://ubertruck-247-mvp-ec.vchiluisa78.chatgpt.site

## Funcionalidades incluidas

- Panel operativo con indicadores de flota.
- Catálogo de unidades, ubicación, capacidad y estado.
- Perfiles de operadores.
- Consulta de disponibilidad.
- Cotizador con modalidad, operador y garantía referencial.
- Solicitudes demostrativas.

## Ejecutar localmente

```bash
npm install
npm run dev
```

El proyecto usa datos de demostración. GPS, pagos, facturación electrónica y firma digital quedan fuera del alcance de esta primera versión.
